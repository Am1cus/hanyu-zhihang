# 网页可读性优化收尾验收

日期：2026-09-13。范围为既有 Vue 前端的可读性与上手流程，后端/模型不重构、不重训。实际编辑目录为原工作区 `project/cold-region-aviation-frontend`，验收后单向同步到本仓库 `platform/cold-region-aviation-frontend`。

## 最终修改

- 延续白底灰绿样式、三入口、关键指标优先、折叠档案和输入详情、手机预警卡片、使用指南。
- 无记录时不再显示误导的 V2 标识；指南说明只有历史视图需要点“跟随最新回放”。
- 默认记录优先选择完整完成、具有后验标签的普通架次，排除 `max_samples` 截短和工程测试；无符合条件的记录时明确说明回退到最新记录。不按模型误差择优。
- 清理看板未使用的导入和计算量。曲线原值、标签对齐、基线与指标计算逻辑保留。
