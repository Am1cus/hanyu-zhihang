# 寒域智航容量预测接口基准测试报告

## 测试说明

- 接口地址：`http://127.0.0.1:8000/predict`
- 测试样本：B5、B6、B7、B18 各 5 组，共 20 组
- 每组输入：连续 10 个循环的温度、风速、电压、电流和 SOC
- 测试范围：各电池后 20% 测试区间，不使用训练区间样本

## 测试结果

| 指标 | 结果 |
| --- | ---: |
| 请求总数 | 20 |
| 成功请求数 | 20 |
| 成功率 | 100.00% |
| 平均响应时间 | 4.0370 ms |
| P95 响应时间 | 4.5587 ms |
| P99 响应时间 | 30.6194 ms |
| 容量预测 MAPE | 4.6039% |

## 验收结论

平均响应时间目标为不超过 150 ms。本次测试通过该目标。

本结果基于本地 macOS CPU 环境和模拟环境特征，仅用于接口原型验证；真实部署性能需要在目标设备和真实飞行数据上重新测试。
