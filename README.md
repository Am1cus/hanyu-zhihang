# 寒域智航 — 极寒环境无人机动力预警与智能调度系统

## 项目简介

本项目针对黑龙江高纬度极寒地区（-25℃及以下）无人机电池性能急剧衰减、航程预测失准的痛点，构建基于LSTM的深度学习动力衰减预测模型，实现从被动电量监测向主动动力预警的跨越。

本项目为大一大学生创新创业大赛作品

## 仓库结构

```text
learn/
├── NasaBatteryTest/     NASA 电池原始数据与早期实验
├── Phase1/              数据处理、特征工程与训练数据集 V1.0
├── Phase2/              LSTM 训练、模型量化与初步验证
├── Phase3/              FastAPI 量化模型推理接口
├── requirements.txt     Python 项目依赖
└── README.md            项目说明
```

## 当前进展

- 已完成 636 条 NASA 电池容量数据的清洗与多特征训练数据集 V1.0。
- 已完成多特征 LSTM 容量预测模型及动态量化版本。
- 已完成本地 FastAPI 推理接口，可使用连续 10 个周期的数据预测下一循环容量。

## 启动推理接口

```bash
.venv/bin/uvicorn Phase3.inference_api:app --host 127.0.0.1 --port 8000
```

启动后打开 `http://127.0.0.1:8000/docs`，可在交互式接口页面测试容量预测。

> 当前模型基于 NASA 电池容量数据和模拟极寒环境特征，仅用于科研原型与技术流程验证，不能直接用于真实无人机安全决策。
