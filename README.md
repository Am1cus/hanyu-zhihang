# 寒域智航 — 极寒环境无人机动力预警与智能调度系统

## 项目简介

省级大学生创新创业项目「寒域智航」，研究低温无人机能耗、任务预算与预警。当前可运行成果是 AirSim 仿真研究平台和离线研究工具，尚未完成真实低温航程预测、提前预警或自动调度验证。

最新状态见 [项目推进台账](docs/PROJECT_PROGRESS.md)，操作说明见 [本地演示](docs/LOCAL_DEMO.md) 与 [完整启动/数据保存说明](demo/README.md)。

## 当前进展

- 已接通 AirSim 数据回放→Spring Boot 持久化→FastAPI 冻结候选推理→未来标签→WebSocket→Vue；可查询、导出和独立复算档案。
- V3 是运动特征残差 LSTM 三种子 FP32 集成，预测未来10秒耗电Ah；已冻结但待新seed独立确认。公式电池数据不能替代真实低温测量，当前网络没有直接输入温度。
- V1/V2、历史实验与负结果保留。V2 旧测试的耗电MAPE约1.335%，历史延续约0.893%，尚未优于最强简单基线。
- 网页展示真实存档和规则预警；离线新增规划、往返预算、Wh/Ah积分与风险事件评价，见 [Phase5说明](Phase5/README.md)。这些工具尚未完成仿真执行闭环或真实飞行验证。
- 低温可用能量、独立确认、MQTT实连/真实多机、边缘设备、24小时可靠性、真机试验及论文/软著正式成果仍待推进，见台账中的团队交付表。

原始数据包需由团队另行提供，数据库、私密配置和本机验收原始档案不随源码发布。现有源码镜像单向同步流程仅用于原开发工作区；新克隆仓库直接使用 `platform/`。

## 启动推理接口

```bash
.venv/bin/uvicorn Phase3.inference_api:app --host 127.0.0.1 --port 8000
```

启动后打开 `http://127.0.0.1:8000/docs`，可在交互式接口页面测试容量预测。

> 当前模型基于 NASA 电池容量数据和模拟极寒环境特征，仅用于科研原型与技术流程验证，不能直接用于真实无人机安全决策。
