# 寒域智航操作手册

这是单机二维软件仿真。默认地图是拟定的东北冰雪景区应用场景，三个巡检点按顺序访问，不涉及真实飞控。

## 第一次启动

1. 解压交付包，进入包含 `competition` 文件夹的目录。准备 Python 3.10 或以上，推荐 3.12。
2. 建立独立环境：`python3.12 -m venv .competition-venv`。
3. 安装锁定依赖：`.competition-venv/bin/python -m pip install -r competition/requirements-lock.txt`。首次安装需要网络；此后本机演示不依赖外网。
4. Mac / Linux 执行 `./competition/start.sh`；Mac 也可以双击 `start.command`。Windows 运行 `competition\start.bat`，按提示先建立环境。
5. 打开 <http://127.0.0.1:8091>。保留服务终端，结束时按 Ctrl+C。

交付包附已构建网页。修改前端源码后，在 `competition/web` 执行 `npm ci`、`npm run build`。不要使用原项目旧 Java、AirSim 或 LSTM 服务替代比赛服务。

## 90 秒演示脚本

| 时间 | 操作与解说 |
|---|---|
| 0～25 秒 | 选“正常巡检·场景1”，分别选择 0℃、−20℃并点“比较两种策略”。指出可用能量随温度变化，总预算含三点停留、最终返程和储备。 |
| 25～40 秒 | 恢复 −10℃，计算后启动“能量优先”任务，显示 20 倍仿真与后端位置。 |
| 40～60 秒 | 点暂停；点“在地图上新增障碍”，在尚未经过的路线上选一个格子。不要选无人机占用航段、基地或已经存在的障碍。点继续，看到下一个节点后的重规划和预算更新。 |
| 60～80 秒 | 指出执行轨迹与新路线；判断时间线记录事件发生的仿真秒及继续或返航原因。 |
| 80～90 秒 | 打开此次任务的完整档案，展示事件和决策，点击导出 JSON。 |

第一次练习可先用 5 倍速熟悉操作。正式演示默认 20 倍速。暂停用于让操作与讲解从容，不改变仿真积分或偷读未来事件。若任务尚未结束，直接进入“结果复查”选择最新档案；不能把当前进度说成完成了三个点。

## 三个页面

**任务预演：**选择场景、温度、储备、策略。比较按钮运行两种策略的完整确定性预演；地图对照可查看各自完整执行轨迹。页面中的初始总预算只使用当前已知风场，后续突风或障碍会使原预算需要更新。实际预演结果包含场景预置事件，两者应分别解释。

**运行与调整：**启动后前端每 200ms 查询后端状态。所有位置、耗能与决策由后端给出。风输入是中部风区域的二维矢量，单位 m/s；强风可能使模型无法保持航向，系统须明确失败原因。障碍只接受地图内整数网格，不能覆盖当前占用航段和基地。

在线预算核算下一点及停留、从该点返程和储备，不等于承诺完成余下所有点。预算不足时尝试返航；确实到达基地后才记“已返回”。“运行已结束”与“三点任务全部完成”是不同状态。

**结果复查：**预演与交互运行均保留记录。导出包含完整遥测，而页面为避免负担只绘制最近 300 个遥测样本。复演会创建新记录，使用原场景和已应用手动事件，原记录保留。服务重启后的历史运行只能复演，不能从旧内存状态继续。

## 复现与核查

```bash
.competition-venv/bin/python -m unittest discover -s competition/tests -v
.competition-venv/bin/python -m competition.evaluate --output output/4C/evidence/formal
```

正式评测为 24 个场景、48 次执行。原始导出中，相邻样本能量用 `((V1×I1 + V2×I2)/2)×Δt/3600` 复算 Wh；电流积分得到 Ah。这里恒定 4.2A，采样含曲线折点，积分可与分段电压曲线一致。请查看独立复算记录中的实际容差，不把 Wh 与 Ah 混用。

相同版本、曲线、场景、种子及事件时间产生相同轨迹和耗能。随机 UUID 和计算耗时不是确定性结果。用结果哈希核验时遵循对应版本导出规范。

## 故障处理

- 打不开网页：查看服务终端是否正常；不要关闭终端。检查是否误打开旧项目端口。
- 8091 被占用：先确认已有服务的身份，可查看 `/api/competition/health`。只停止自己启动的比赛服务；不要结束不明进程。
- 页面提示参数不足：检查 `competition/data/p42a_reference.json`，不要临时用猜测的低温折减系数补齐。
- 新增障碍被拒绝：选择地图内空白网格，避开基地和无人机当前航段。
- 网络断开或后端停止：页面保留最后一帧，不推造位置。现场播放“实际运行备用录屏”，清楚说明这是同版本录屏。
- 字体或视频在 PowerPoint / WPS 中异常：在实际答辩电脑安装交付字体并检查播放；PDF 可作为版式备用，视频独立播放。

## 答辩前学生必须完成

真实需求核对、同学试用、主要算法理解、目标电脑字体和视频检查、三轮两人完整计时演练。自动化浏览器操作与合成旁白练习视频不能代替这些任务。报名身份、导师、签名及作品声明必须如实填写。
