# 寒域智航操作手册

这是单机二维软件仿真。默认地图是拟定的东北冰雪景区应用场景，三个巡检点按顺序访问，不涉及真实飞控。

## 第一次启动

1. 解压交付包，进入 `learn`（包含 `competition` 文件夹）。推荐准备 Python 3.12，当前独立复现按3.12与锁文件核验。
2. 建立独立环境：`python3.12 -m venv .competition-venv`。
3. 安装锁定依赖：`.competition-venv/bin/python -m pip install -r competition/requirements-lock.txt`。首次安装需要网络；此后本机演示不依赖外网。
4. Mac / Linux 执行 `./competition/start.sh`；Mac 也可以双击 `competition/start.command`。Windows先运行 `py -3.12 -m venv .competition-venv`，再运行 `.competition-venv\Scripts\python.exe -m pip install -r competition\requirements-lock.txt`，最后运行 `competition\start.bat`，也可双击交付包根目录 `启动Windows.bat`。
5. 打开 <http://127.0.0.1:8091>。保留服务终端，结束时按 Ctrl+C。

交付包附已构建网页。修改前端源码后，在 `competition/web` 执行 `npm ci`、`npm run build`。不要使用原项目旧 Java、AirSim 或 LSTM 服务替代比赛服务。

## 90 秒主演示：先留回程，再做巡检

主演示使用“低预算·场景1”（`low_budget-s1`）、能量策略、55%初始SOC（容量比例）、20%参考储备、20倍仿真。点击任务预演页的“看懂低温取舍”载入0℃和−20℃的完整软件预演对照；点击“运行 −20 °C 案例，观察一点后返程”开始现场运行。对照结果来自真实软件执行，不是起飞预算的承诺。

| 时间 | 操作与解说 |
|---|---|
| 0～15 秒 | 展示对照：“同一低预算场景，0℃实际完成3/3并返回；−20℃实际完成1/3并返回”。分别指出完成点数和返回状态。 |
| 15～30 秒 | 指向−20℃整轮初始预算：“可用27.19 Wh，三点巡检连同回程和储备需29.68 Wh，整轮不够；当前预算支持第一点”。 |
| 30～45 秒 | 点击运行−20℃案例。保留仿真时间、20倍标识，指出图标由后端执行推进，不手动选择返航或结束任务。 |
| 45～60 秒 | 看第一点后的“下一点预算不足”判断和返回路线。确实到达基地后才说“已返回”；需要暂停帮助解说时随后继续。 |
| 60～75 秒 | 打开本次任务档案：“已巡检1/3、已返回、部分任务后返回”，三个状态一起展示。 |
| 75～90 秒 | 查看返航原因和预算，导出JSON：“条件、判断与轨迹可以一起复查”。 |

冻结−20℃个案用514.38仿真秒完成一点并返回，20倍连续播放部分约25.7秒；操作、暂停、计算及渲染会增加墙钟时间。这个换算不是已经完成90秒真人计时演练。第一次练习可用5倍速熟悉，正式展示用20倍并以实际状态为准。如果尚未到达基地，不能提前说“已返回”。

0℃起飞保守预算支持2点，但逐点重算的实际执行结果是3点；−20℃初始支持1点，实际为1点。整轮预算采用上界功率，执行按电压曲线积分，二者不能混成一个结果。完成第一点后的−20℃不足量约0.00743 Wh，仅为模型触发值，不宣传真实设备的精确危险阈值。

2026-10-04新版90秒实际备用录屏已按低预算自动返回案例重新录制：只创建任务，未用取消或人工返航替代返回；原档与媒体来源记录一并交付。9分钟合成旁白练习视频同步此版本。旧正常任务避障录屏留在私有历史构建目录，不作为当前主演示。录屏和合成旁白不代替学生真人彩排。

## 补充演示：正常场景动态障碍

需要展示条件变化时，点击“加载避障补充情景”，载入“正常巡检·场景1”（`normal-s1`）、−10℃、能量策略、20%储备，计算后启动。暂停，点“在地图上新增障碍”，选择尚未经过的路线格点，或通过整数坐标输入提交；避开基地、当前占用航段和已经封锁的格点。继续后，在下一节点观察重新规划、预算和事件记录。该补充场景和手动事件另存档案，不混入冻结低预算示例的数字。

组员提交的`2a48f858…`三障碍档案已经核验：确实完成3/3并返回，4320m、930.57仿真秒、16.158693参考Wh，相同配置移除手动事件的软件基线为4160m。另一个取消档案`eb4d87db…`的首段只是同长度换路，没有增加160m；人工结束时1/3、未返回，不能当成完整绕行成功例。

## 三个页面

**任务预演：**选择场景、温度、储备、策略。比较按钮运行两种策略的完整确定性预演；地图对照可查看各自完整执行轨迹。“整轮初始预算”只使用起飞时当前已知风场；“预演执行结果”是在执行过程中实际应用场景事件后的结果。后续突风或障碍会使原预算需要更新，规划器不读取未来事件。

**运行与调整：**启动后前端每 200ms 查询后端状态。所有位置、耗能与决策由后端给出。风输入是中部风区域的二维矢量，单位 m/s；强风可能使模型无法保持航向，系统须明确失败原因。障碍只接受地图内整数网格，不能覆盖当前占用航段和基地。

在线预算核算下一点及停留、从该点返程和储备，不等于承诺完成余下所有点。预算不足时尝试返航；确实到达基地后才记“已返回”。暂停只是暂不推进，可继续；“结束任务”是操作员取消，当前位置可能不在基地；“运行已结束”与“三点任务全部完成”也是不同状态。

计算耗时用毫秒表示，事件到下一次决策的等待用仿真秒表示，20倍只是仿真播放速度。这三个指标不能互换，也不能描述为真实飞控响应性能。

**结果复查：**预演与交互运行均保留记录。导出包含完整遥测，而页面为避免负担只绘制最近 300 个遥测样本。复演会创建新记录，使用原场景和已应用手动事件，原记录保留。服务重启后的历史运行只能复演，不能从旧内存状态继续。

## 新版操作审计与旧记录

2026-10-04新增`execution_audit`（schema 1），在API导出与状态中附带操作记录。成功的创建、暂停、恢复、取消及复演来源关系持久保存在SQLite；每条含仿真时间、服务记录时间、操作前后状态与来源。正常关闭服务造成的暂停标为`server_shutdown`，与操作员暂停区分。无效或被拒绝的操作不是已执行控制，不写成成功记录。

审计独立于仿真核心与`result_sha256`；服务记录时间不是外部签名时间戳。旧档案缺少创建、暂停/恢复或复演来源信息时标为未知，不能从两个结果相同补造历史。升级后的新操作可以另行记录，但不会回填升级前的未知部分。

组员旧档`2a48f858…`与标为复演的`40aa8e89…`确定性内容完全一致；旧导出没有来源ID，所以只证明结果一致，不能单凭附件证明点击复演的创建关系。新版来源关联应在“操作记录”及新导出的`execution_audit.origin.source_run_id`核查。

## 复现与核查

```bash
.competition-venv/bin/python -m unittest discover -s competition/tests -v
.competition-venv/bin/python -m competition.evaluate --output output/4C/evidence/formal
```

正式评测为 24 个场景、48 次执行。原始导出中，相邻样本能量用 `((V1×I1 + V2×I2)/2)×Δt/3600` 复算 Wh；电流积分得到 Ah。这里恒定 4.2A，采样含曲线折点，积分可与分段电压曲线一致。请查看独立复算记录中的实际容差，不把 Wh 与 Ah 混用。

相同版本、曲线、场景、种子及事件时间产生相同轨迹和耗能。随机UUID、CPU耗时和操作审计不是确定性结果。`result_sha256`覆盖`summary / telemetry / decisions / events`四项；导出文件SHA用于保存完整性，两个复演导出不需要逐字节相同。遥测以0.5秒网格推进，曲线节点、到达与事件边界还会增加样本，不能假设每对相邻样本都相隔恰好0.5秒。

本轮组员材料核验见`output/4C/evidence/team/20261004/audit.md`与`audit.json`：11个文件清单哈希一致，四份运行档案积分、守恒、轨迹和确定性重执行通过；实际是两份不同完整执行内容、一份重复内容、一份取消内容。它们不构成四次独立实验，也不替代正式24场景48执行。Windows启动和操作截图已提交，但未在该电脑完成独立干净环境验收。

## 故障处理

- 打不开网页：查看服务终端是否正常；不要关闭终端。检查是否误打开旧项目端口。
- 8091 被占用：先确认已有服务的身份，可查看 `/api/competition/health`。只停止自己启动的比赛服务；不要结束不明进程。
- 页面提示参数不足：检查 `competition/data/p42a_reference.json`，不要临时用猜测的低温折减系数补齐。
- 新增障碍被拒绝：选择地图内空白网格，避开基地和无人机当前航段。
- 网络断开或后端停止：页面保留最后一帧，不推造位置。现场播放“实际运行备用录屏”，清楚说明这是同版本录屏。
- 字体或视频在 PowerPoint / WPS 中异常：在实际答辩电脑安装交付字体并检查播放；PDF 可作为版式备用，视频独立播放。
