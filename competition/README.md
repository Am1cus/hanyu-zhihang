# 寒域智航比赛版

东北冰雪景区无人机巡检任务决策与仿真验证平台。用一句话理解：**先把下一点的巡检、返程和储备算清楚，再决定继续还是返航。**作品为单机、固定高度、二维的软件仿真，不连接真实飞控。主赛道按“软件应用与开发—算法设计与应用”准备。

## 启动

在 `learn` 目录中运行 `./competition/start.sh`，或在 Mac 双击 `competition/start.command`。然后打开 <http://127.0.0.1:8091>。首次依赖准备见下文；打包交付中包含已构建网页，日常演示不需要 Node.js。

推荐使用 Python 3.12；当前独立复现环境按 3.12 与锁文件核验。首次安装建立专用环境，不借用旧项目环境：

```bash
python3.12 -m venv .competition-venv
.competition-venv/bin/python -m pip install -r competition/requirements-lock.txt
```

源码开发时在 `competition/web` 执行 `npm ci` 和 `npm run build`。启动只监听本机，退出终端不会清空已保存运行档案。Windows 在 `learn` 目录用 `py -3.12 -m venv .competition-venv`，再执行 `.competition-venv\Scripts\python.exe -m pip install -r competition\requirements-lock.txt`，最后双击交付包根目录的 `启动Windows.bat`，或运行 `competition\start.bat`。首次安装依赖需要网络。

## 三个入口

1. 任务预演：选择温度、场景与规划方法，查看去返程和储备预算。
2. 运行与调整：后端执行仿真，支持暂停、恢复、障碍和风事件。移动位置来自后端状态。
3. 结果复查：查看轨迹、决策记录、实际仿真耗能和任务完成情况，导出档案，复演生成新运行。

## 90 秒讲清一个取舍

主演示采用 `low_budget-s1`，能量策略、55%初始容量、20%参考储备。同一条件下，完整软件预演在 **0℃实际完成3/3并返回，−20℃实际完成1/3并返回**。点击“看懂低温取舍”查看对照，再运行−20℃案例，观察后端完成第一点后重新核算并返回。详细操作见 [操作手册](OPERATION_MANUAL.md)。正常场景的动态障碍绕行作为补充演示。

必须区分：**整轮初始预算是估算，完整预演是已经跑完的软件结果，运行中预算只检查下一点及返程与储备。**0℃起飞保守预算支持2点，逐点执行最终完成3点；−20℃初始支持1点，最终完成1点。估算采用上界功率，执行按厂家曲线积分，初始支持点数不是硬性任务上限或未来保证。

−20℃初始可用27.19 Wh、整轮需求29.68 Wh。到达基地才记“已返回”；“暂停”“人工结束”均不能作为完成巡检或返回的证据。

## 数据和边界

- 数据来源为 `LOCAL_2D_SIM`，场景是合成软件地图，不对应真实景区。
- `data/p42a_reference.json` 直接从 Molicel P42A v1.7 原始 PDF 的矢量曲线提取。原始曲线和参考能量不是本团队实测。
- 曲线测试为 4.2A 恒流、2.5V 截止，23℃充电。使用理想一致电芯 4S1P 虚拟组；不代表高倍率无人机电池、老化、自热或 BMS 截止特性。
- −10℃按归一化容量节点插值电压，再积分 Wh。禁止温度外推。环境与电芯达到热平衡是情景假设。
- 执行器用原始 V/I/t 积分评价，规划器用声明的保守电压估算。两种规划采用同一估算器和储备规则，规划器不知道未来事件。
- Ah、Wh、SOC 和航程分别解释；这里只报告给定模型下的仿真任务表现。
- 原 V3 LSTM 保留在旧研究模块。它预测未来10秒耗电Ah，尚待独立确认，不用于本二维任务控制。

## 文件与复现

任务服务使用自己的 SQLite，不修改旧 H2 数据库、旧 AirSim 档案或冻结模型。运行档案包含场景、温度、策略、原始遥测、事件、轨迹和决策依据。正式场景清单与结果在交付目录 `output/4C/evidence`，学生任务、讲稿、PPT与视频分目录保存。

2026-10-04新增 API 操作审计 `execution_audit`（schema 1）：保存创建、成功的暂停/恢复/取消及复演来源关系，操作记录独立持久化；不改变 `mission-core-v1.1` 的确定性结果与 `result_sha256` 覆盖范围。旧档案缺少的控制历史或来源标为“未知”，不从结果相同推造暂停记录或复演关系。复演生成新ID，保留原档案；服务重启后的历史运行只能复演，不能续控。
