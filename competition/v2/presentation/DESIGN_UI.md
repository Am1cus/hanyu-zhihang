# 寒域智航 v2 界面设计

更新：2026-10-22。适用于 `live.html`，即本机 8094 巡看演示入口。

## 视觉方向

根据用户要求，采用接近苹果桌面应用的浅色工作台风格。使用 `ui-ux-pro-max` 的简洁布局、信息层级、键盘操作和响应式建议，并按当前仿真工具调整；未采用营销页面结构。

- 系统字体优先：macOS / iOS 使用系统西文字体与苹方，其他平台回退到本机字体。无需在线字体或图片。
- 浅灰画布 `#f5f5f7`，白色面板，主文字 `#1d1d1f`，辅助文字 `#68686d`。
- 蓝色 `#0066cc` 用于主操作、当前导航和待执行路线；绿色表示完成，紫色虚线表示返程，琥珀色表示警示或新增禁入区。所有状态同时提供文字说明。
- 20px 主面板圆角、11px 控件圆角、细分隔线、轻阴影。数字使用等宽数字特性。
- 任务总览、任务配置、实时巡看、结果复查是同一工作台的锚点导航，支持浏览器前进、后退与直接定位。

## 布局与交互

桌面使用固定侧栏，地图与当前决策并列，清单与记录放在下一行。1000px 以下切换单列内容，760px 以下侧栏转为顶部导航，440px 以下任务清单与次要操作纵向排列。

讲解模式收起导航、标题和次要说明，突出地图、决策与结果；仍可退出、暂停、继续、结束、导出和复演。小屏讲解模式保持单列。

保留原有 API、执行器、规划算法、运行数据库与模型边界。图中位置来自后端状态，不添加模拟位置动画。界面新增加载按钮文案、当前阶段语义、状态色和明确的初始等待态。

控件至少44px高，输入始终有标签；保留跳到主内容的链接、键盘焦点、状态播报。支持 `prefers-reduced-motion`。地图、侧栏图标均使用内联 SVG。

## 维护与验证

页面保留为单个 HTML 文件，内含 CSS 和 JavaScript，由现有服务直接提供，不需要新增依赖或构建步骤。样式使用语义变量；新的运行状态应同步检查状态文字与色彩。

验证包含现有17项运行测试，以及真实浏览器中的配置、启动、暂停、继续、事件、结果、导出、复演和讲解模式。另检查375、768、1024、1440像素布局、横屏、减少动态效果与键盘焦点；具体记录和截图保存在工作区 `output/playwright/apple-ui/`。这些检查不构成完整无障碍认证。
