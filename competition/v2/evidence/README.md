# 公开证据与结果说明

本目录发布已有软件实验的机器报告和**全部逐项统计**，不是精选成功案例。没有真实飞行数据。发布日为2026年10月28日；各报告保留原验证日期。

在计入估计误差的144组同条件比较中，统筹安排相对就近安排为38组更好、96组持平、10组更差，平均达标完成分分别为50.7与46.1；低预算分组有弱项。完成分要求实际模型返程且满足储备，再按合成任务权重归一，不等于实际业务收益或实飞成功率。详细解释见[10月22日记录](../DAY22.md)。

储备比例补充使用同一批已用场景，不能叫作新的未见验证；其中20%设置的1,152项属于原结果复核，不能与原批次相加宣称独立样本增加。降低储备门槛不自动等于算法改善。见[10月27日记录](../DAY27.md)。

完整配置、原始遥测与源码冻结包保存在团队本地交付档案，未随本次源码发布。历史文档中的`output/4C/...`指向这些本地档案，GitHub克隆不包含该目录；运行主程序和软件检查不依赖它。公开摘要不能代替完整原始档案审计。

原87项日志仅将本机绝对路径替换为`<repository>`，没有删除检查、警告或失败记录。几何一致性测试需要的0.2开发地图已作为仓库夹具保留，原文件字节与指纹不变。
