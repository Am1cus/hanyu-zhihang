# 现在就能用：寒域智航试用说明

更新：2026年10月29日。本轮是可操作的本机二维仿真，不控制真实无人机。当前界面保留作技术验证入口，后续可独立重写。

## 在这台 Mac 上打开

双击项目根目录的 **启动寒域智航.command**。程序会检查环境、启动服务，再自动打开浏览器。保持启动窗口开着；关掉网页不会停止后台仿真。

也可双击本目录 `start_v2.command`。如果浏览器没有自动打开，手动访问 <http://127.0.0.1:8094/>。重复启动会打开已有服务，不会再开第二个服务。停止时在启动窗口按 **Control+C**。

## 第一遍只做这五步

1. 保持默认的“前方受阻 · 任务调整”和“先挑划算的”，点击 **开始巡看**。
2. 看地图上的无人机和右侧“下一步，为什么”。默认20倍播放，第32仿真秒会出现预设障碍。
3. 点击 **暂停**，读一遍系统改了什么；再点 **继续**。也可以在航行时点击“在前方加入禁入区”。
4. 等它实际回到管理站，查看做完几个点、耗了多少电、还有哪些待安排。默认演示约一分钟，电脑性能和暂停时间会影响实际时长。
5. 点击 **导出完整记录** 保存JSON；点击 **按原配置复演**，查看同一任务从头再走一次。JSON供程序复核，不要求你手算所有行。

只想试低温效果：在开始前展开“温度、电量与播放速度”，先看0℃的预算，再切换−20℃看同一设置的变化。想展示任务取舍可把初始剩余Ah调为55%，或比较“先去近处”和“把整趟一起算”。这些是演示条件，不承诺每种条件都节能。

## 遇到这些情况怎么办

| 情况 | 程序现在怎样处理 |
|---|---|
| 不小心刷新网页 | 找回最近查看的运行；后台仍在运行则继续显示，已暂停则保留暂停 |
| 提示“连接中断” | 旧画面停止更新、操作暂时禁用；先确认启动窗口仍开着，等待自动重连或点“重新连接” |
| 不确定一次点击是否成功 | 重连先读取后台记录，不自动重复发送操作；可在历史运行里核对 |
| 退出服务后重新启动 | 已保存记录仍可查看和导出；标明“已归档”，只能从头复演，不能接着上次位置飞 |
| 电量太少、温度超范围或极端强风 | 分别显示未起飞、信息不足或运行失败；不会显示成成功返回 |
| 提示端口被其他程序占用 | 不会关闭其他程序；在命令行加 `--port 8097`，打开相应地址 |

浏览器本地存储被禁用时，刷新找回可能需要从“历史运行”手动选择。源码版记录在仓库父目录的 `output/4C/v2/runtime/missions-v2.sqlite3`；带`PORTABLE_PACKAGE`标记的独立包记录在包内`runtime/missions-v2.sqlite3`，均不在浏览器内。新功能验证使用独立测试库，不污染日常演示记录。

## 给另一台电脑的说明

当前 Mac 已验证可启动。Windows入口是本目录 `start_v2.bat`，需要先安装Python 3.12及Python Launcher；**本轮尚未在Windows实机运行**。不要使用旧版 `competition/start.bat` 代替v2入口。

源码克隆版第一次缺少环境时，启动器会在项目内创建 `.competition-venv` 并联网安装固定版本依赖；安装完成后演示不需要互联网。带`wheelhouse`的独立包首次安装依赖也可离线，Python3.12本身须预装。Apple芯片Mac的全新环境检查已完成，Windows目标电脑仍待核验。不要单独复制启动脚本。交付包操作见[PORTABLE_README.md](PORTABLE_README.md)。

仅检查当前解释器和依赖，不启动程序：在`learn`目录运行 `.competition-venv/bin/python competition/v2/launch.py --check`。

本作品的低温、电量和风来自已说明的参考模型。没有实飞、拍照识别或真实配送验证；地图上的停留代表一次模拟补充巡看。
