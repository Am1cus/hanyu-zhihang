# 寒域智航网页设计约定

更新：2026-10-04。使用本机 ui-ux-pro-max skill 的设计系统、Vue 与 UX 检索指导；以下为结合实际项目筛选后的约定。

## 目标与取舍

评委先理解“巡检、返程、储备三笔账”，再看路线与执行结果。维持东北冰雪主题、雪白画布、松绿色强调，采用 Minimalism & Swiss Style 的信息层级、留白与明确对齐。检索中的营销 Hero/联系销售模式与本机任务工具不匹配，未采用；无需外部图片、在线字体或图标服务。

## 界面规范

- 桌面：固定深松绿导航；配置、地图、预算三列。小于1280px预算独立整行；小于900px导航移到顶部；小于620px按配置、预算、地图/策略顺序阅读。
- 预算：当前可用与所需的 Wh 数值突出；巡检绿、返程蓝、储备琥珀色，同时使用文字和01/02/03编号。所有数据由后端返回。
- 运行：当前判断独立展示，条件变化等待重算使用琥珀色和明确文字，停止记录使用中性色，不显示旧预算为当前有效预算。
- 字体：本机思源黑体优先，其次系统中文字体。主体14–16px，次级12–13px，页面标题26–30px，预算30px；数值使用等宽数字。
- 控件：最小44px高度，手机输入16px；键盘焦点使用蓝色3px描边；有跳转工作区链接、导航当前页和策略选中状态。
- 地图：后端真实仿真位置，不加入装饰性位置动画；点击障碍提供坐标输入替代。无效坐标禁用发送，占用航段/基地由后端拒绝。
- 反馈：状态变化适量礼貌播报；200ms遥测不设置逐帧播报。尊重减少动态效果偏好。
