# 比赛版独立前端

此目录不修改旧研究平台前端。Vue 3.5.32、Vite 5.4.21 与 Vue 插件 5.2.4 沿用本机已经安装的版本；依赖版本及完整性保存在 `package-lock.json`。

```bash
npm ci
npm run build
```

生成 `dist/`，由比赛服务在 `127.0.0.1:8091` 提供静态网页。日常演示无需运行 Vite。开发时先启动比赛后端，再执行 `npm run dev`；Vite 将 `/api` 转发到 8091。

三个入口为任务预演、运行与调整、结果复查。预演同时运行距离/能量策略；全任务预算基于当前已知风场，不预知未来事件。运行位置只来自后端 `position`；仅 RUNNING 状态以 200ms 间隔读取，前一个读取结束后安排下一个，离开组件时停止并取消读取。暂停与终态不轮询。

地图新增障碍和风按钮提交真实后端事件，返回状态后才更新画面。任务复演调用 `replay_of_run_id` 创建新运行，不修改原档案。JSON 导出链接访问后端完整档案。

页面持续标注 `LOCAL_2D_SIM`，说明厂家源曲线条件与 −10℃插值，不把软件模型描述成团队实测。旧 LSTM 未接入本任务控制流程。
