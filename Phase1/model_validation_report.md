# 寒域智航模型初步验证报告

## 1. 验证目的

本报告记录“寒域智航”第二阶段的基础模型训练与动态量化验证结果。目标是在现有公开电池数据和模拟极寒环境特征的基础上，完成容量预测 LSTM 原型及其轻量化版本，为后续接口集成与仿真验证提供模型文件。

## 2. 数据与特征

训练数据集为 `training_dataset_v1.csv`，共 636 条样本，包含 B5、B6、B7、B18 四组 NASA PCoE 锂电池循环容量数据。数据由 MATLAB `.mat` 文件导出，并添加模拟的极寒飞行环境特征。

模型输入特征如下：

| 特征名 | 含义 |
| --- | --- |
| temperature_C | 模拟环境温度，已标准化 |
| wind_speed_ms | 模拟环境风速，已标准化 |
| voltage_V | 根据容量估算并加入噪声的电压，已标准化 |
| current_A | 模拟放电电流，已标准化 |
| soc_pct | 荷电状态百分比，保持原始尺度 |

预测目标为 `capacity_Ah`。`cycle` 与 `battery_id` 用于序列排序和数据分组，不作为模型输入。

## 3. 训练与测试方法

采用滑动时间窗口构建样本：使用前 10 个循环的多特征数据预测第 11 个循环的容量。每块电池独立构造序列，避免不同电池之间的循环记录混合。

每块电池按时间顺序划分数据，前 80% 循环用于训练，后 20% 循环用于测试。最终得到 467 个训练样本和 129 个测试样本。

LSTM 模型结构如下：

| 模块 | 配置 |
| --- | --- |
| LSTM | input_size=5，hidden_size=64，num_layers=2，dropout=0.2 |
| 输出层 | Linear(64, 1) |
| 损失函数 | MSELoss |
| 优化器 | Adam，学习率 0.001 |
| 训练轮数 | 300 |
| 批大小 | 32 |

## 4. 本次复现结果

本次验证在 CPU 环境运行，模型参数量为 51,521。原始模型的整体测试集 MAPE 为 6.4973%。

对 LSTM 层应用 PyTorch 动态 INT8 量化，macOS 环境使用 `qnnpack` 量化后端；量化模型在相同的 129 个测试样本上评估。

| 模型版本 | 模型大小(KB) | 平均推理时间(ms) | MAPE(%) |
| --- | ---: | ---: | ---: |
| 原始模型 | 204.69 | 2.6523 | 6.4973 |
| 量化模型 | 62.62 | 3.8499 | 6.9465 |

量化后模型体积减少约 69.4%，MAPE 增加 0.4492 个百分点，精度损失低于项目技术路线中“量化精度损失小于 2%”的目标。当前 macOS `qnnpack` 后端下，小批量推理时间未缩短；量化的主要收益是模型存储体积明显减小。

## 6. 当前局限性

本阶段使用 NASA 公开电池容量数据，并基于规则生成温度、风速、电压、电流和 SOC 等模拟特征。因此，当前结果用于验证数据处理、LSTM 训练和模型量化的技术流程，不能直接表述为真实极寒飞行环境下的预测精度。

后续获得真实低温飞行数据后，需要使用实测温度、电流、电压、风速和容量数据重新训练或微调模型，并在独立实测数据上进行评估。当前收到的 AirSim 数据暂不接入本训练集，保留为第三、四阶段仿真与接口测试的候选数据。
